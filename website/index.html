GitHub

proskills

One library of agent skills. Curated profiles for each task — no context bloat.

$ bun install -g proskills skills
Copy
i.

Canonical library

Every skill lives once, in ~/.agents/db/skills.

ii.

Isolated profiles

Carve subsets per task. Symlinks back to the library — no duplication.

iii.

Agent-ready XML

One command emits a manifest your agent can drop into a prompt.

Fig. i Quick start 
proskills init
proskills add vercel-labs/agent-skills/skills/find-skills
proskills profile create my-tools
proskills profile add my-tools find-skills
proskills profile get-skills my-tools
─── Output ──────────────────────────

    <name>find-skills</name>
